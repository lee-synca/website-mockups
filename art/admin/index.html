A·R·T

Site editor

Add or update events and news on the A.R.T website. Changes go live automatically about a minute after you save — no code needed.

Open the editor →

  1. Sign in with GitHub (use the shared A.R.T login).
  2. Choose the website-mockups project.
  3. Pick A.R.T — Events / shows or A.R.T — News.
  4. Add or edit an entry — upload a poster/image, fill the fields.
  5. Hit Save. The site updates itself shortly after.
First time only: the shared account needs to be given access to the repository, and Pages CMS authorised. Ask whoever set up the site if you can’t get in.
